# 게임 팔레트

최신 내보내기 PNG의 알파가 0보다 큰 픽셀에서 추출한 sRGB 31색이다. 합성 화면과 GIF의 미리보기용 색은 제외했다. [project.json](project.json)은 중복을 제거한 전체 색 목록이다.

| 에셋 | 실제 사용 HEX |
| --- | --- |
| 마법사 몸체 | `#222034`, `#28283F`, `#393B5B`, `#454568`, `#4F3333`, `#505276`, `#6A4757`, `#8B6755`, `#E4AA84`, `#F8CFAB` |
| 시전 효과 | `#589DC8`, `#78CBF4`, `#F0FCFF` |
| 슬라임 몸체 | `#23361E`, `#48643C`, `#638752`, `#86A866`, `#BEDD90` |
| 초원 지형과 원경 | `#68865C`, `#749466`, `#7CA06E`, `#8FAF74`, `#91C7C0`, `#99B77D`, `#AAC586`, `#D3DAA5`, `#D88475` |
| 주문 패널과 슬롯 | `#222034`, `#28283F`, `#454568`, `#505276`, `#589DC8`, `#ADE9FF`, `#EAB853` |
| 번개 매직 볼트 | `#367CB0`, `#589DC8`, `#78CBF4`, `#ADE9FF`, `#F0FCFF` |
| 그림자 | `#354568`, `#749466`, `#7CA06E` |

마법사 시전 시트는 몸체 10색과 시전 효과 3색을 함께 쓴다. 슬라임 그림자는 `#354568`에 알파 56, 93, 118을 적용한다. 마법사 그림자의 `#749466`, `#7CA06E`는 불투명하다.

동작별 제작 허용색은 `hood_staff_32_quick.json`, `hood_staff_32_cast_quick.json`, `meadow_slime_attack.json`에 있다. 초원은 `hood_staff_32_meadow.json`, 번개 볼트와 모바일 UI는 각 매니페스트 및 작업 폴더에 기록한 허용색을 사용한다.

팔레트 기준은 [최신 게임 에셋](../exports/INDEX.md)의 배경·UI·캐릭터·번개 매직 볼트 PNG다. 마법사의 이전 단일 투사체는 번개 매직 볼트로 교체했다.
