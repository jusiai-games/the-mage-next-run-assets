# The Mage Next Run · 초원 화면 시안

`mage-next-run-visual.html`을 브라우저에서 열면 설치 없이 작동한다. 오른쪽 **화면 바로 보기**에서 11개 화면을 각각 열 수 있다. 전투에서는 주문 카드를 클릭하거나 1–3 키를 사용한다. 마력 폭발은 별을 마우스나 터치로 그린다. 키보드는 별 화면에서 1 → 2 → 3 → 4 → 5 → 1 순이다.

스테이지 1은 5개 웨이브다. 승리하거나 실드가 무너지면 다음 화면으로 넘어간다. 화면 전환을 빠르게 검토할 때는 오른쪽의 보상, 후퇴, 클리어 바로 가기를 사용한다. 웨이브 타이밍과 보상 및 강화 수치는 시연용이다. 별 입력 동안 전투는 멈춘다. 스테이지 2는 진입 화면까지 연결했다.

## 주문 장착

딤 처리된 전투 화면 위에 장착 슬롯 3개와 보상 손패가 열린다. 손패는 좌우 스와이프하거나 화살표 버튼으로 넘긴다. 카드를 위로 끌기 시작하면 넣을 수 있는 슬롯이 표시된다. 새 주문은 빈 슬롯에 놓고, 보유한 주문은 같은 카드 위에 놓아 레벨을 올린다. 키보드나 클릭으로는 손패 카드를 선택한 후 슬롯을 선택한다. 첫 웨이브에서 받는 주문 보상은 한 장이다.

손패는 원소별 삽화, 짙은 주문명 띠, 넓은 밝은 설명란을 가진 44×64px 세로 카드다. `assets/ui/hand-*.png`에 글자 없는 카드 앞면을 저장하고, 주문명·효과·장착 조건은 화면의 텍스트로 표시한다.

새 시안은 어두운 삽화 창, 황동색 장식, 양피지 이름판과 설명 칸을 쓴다. 카드 삽화 원본과 장착 화면 미리보기는 `../spell-card-concepts/`에 있다.

초원 타일과 덤불에는 이번 화면에서 사용할 밝은 황록색 후보를 적용했다. 변경 HEX는 `assets/meadow-palette-remap.json`에 있다. 아틀라스와 타일 ID를 사용해 합친 지형이 `meadow-terrain.png`와 픽셀 단위로 일치하는지 확인했다. PNG를 게임에서 사용할 때는 최근접 필터를 사용한다.

UI PNG는 Windows에서 Pillow를 설치하고 `python ui_art.py assets/ui`로 다시 만들 수 있다. 나무 버튼은 32×24px, 창은 32×32px 논리 격자로 만들었다. 모서리의 조약돌이 늘어나지 않도록 9슬라이스 경계는 상하 6px, 좌우 8px로 설정했다. 브라우저는 게임 폭에 따라 프레임의 가장자리를 1배, 2배, 3배로 그린다. 방어막은 정상·피격·약화 이미지가 있으며 보호막 내부에 부분 투명 픽셀을 사용한다.
