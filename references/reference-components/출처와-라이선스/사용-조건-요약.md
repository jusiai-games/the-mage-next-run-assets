# UI 레퍼런스 출처와 사용 조건

2026-11-15 기준. 광고 수익을 내는 게임을 상업용으로 보고 공식 배포 페이지를 확인했다. 로컬의 `REFERENCE.zip`에는 원본 경로를 대조했고, Questwood와 Foozle은 동봉된 문구도 확인했다.

## 프로젝트에서 제외한 무료판

사용자 결정으로 아래 세 무료판은 프로젝트 파일, UI 레퍼런스, 생성 입력에서 제외한다.

| 무료판 | 확인한 조건 |
| --- | --- |
| [Qoupy's Rock, Ore, and Gem Nodes](https://qoupy.itch.io/qoupys-rock-ore-and-gem-nodes) | `Qoupy's_ROGNs_Free.zip`은 비상업 전용. 별도 Premium 파일은 상업 이용을 허용한다. |
| [Cozy Interior · shubibubi](https://shubibubi.itch.io/cozy-interior) | Free는 비상업 전용. Complete는 상업 이용을 허용한다. 페이지가 소개하는 영화 포스터 같은 제3자 소재의 권리까지 확인되지는 않았다. |
| [Tiny Farm RPG · Maeve](https://maevedevs.itch.io/farm-rpg) | 상업 이용 문구의 표제가 Full version license다. 무료판의 상업 이용 허용은 확인하지 못했다. |

| 출처 | 확인한 파일 | 사용 범위 |
| --- | --- | --- |
| [Questwood Pixel UI 1.2 · breathinghuman](https://breathinghuman.itch.io/questwood-pixel-ui-200) | `Questwood-Pixel-UI-Complete-v1.2/` | 권리자가 보유한 권리 범위에서 상업 게임에 사용·수정 가능. 완성된 게임에 포함 가능. 원본을 단독 파일·에셋 라이브러리로 재배포하거나 재판매하는 것은 금지. 크레딧은 선택. AI 사용을 공개했으며 제3자 권리 클리어런스는 보증하지 않는다. |
| [Pixel Magic Effects · Foozle](https://foozlecc.itch.io/pixel-magic-sprite-effects) | `Foozle_2DE0001_Pixel_Magic_Effects/` | CC0 1.0. 상업 이용·수정·저작권 범위의 재배포 가능. 크레딧 의무 없음. |
| [Fantasy Card Assets · cafeDraw](https://cafedraw.itch.io/fantasy-card-assets) | `pixelCardAssest*`, `cardBacks.png`, `cardbacks4092021.png`, `cardRIPfx/`, `cardripFX_spritesheet.png`, `cardSHEENfx/`, `squareCircle_vector.png` | 배포 페이지에 CC0 1.0 및 상업 사용·수정 허용 표시. 2023 카드 뒷면에 포함된 SnoopethDuckDuck 아이콘은 cafeDraw가 두 제작자의 크레딧을 선택 사항으로 명시했다. |
| [UI User Interface Pack - Medieval · ToffeeCraft](https://toffeecraft.itch.io/ui-user-interface-medieval) | `MediavelFree.png` | 상업·개인 프로젝트 사용과 수정 허용. 에셋 재배포·재판매 금지. |
| [Ore & Gem · Kelano Studio](https://kelano-studio.itch.io/ore-gem-50-minerals-32x32) | `OreAndGem/` | 상업·개인 사용과 수정·재채색 허용. 에셋 팩 재판매 금지. 크레딧은 선택. |
| [UI User Interface Pack - Elegant · ToffeeCraft](https://toffeecraft.itch.io/ui-user-interface-pack-elegant) | 무료 파일 `FreeButtons.png` | 페이지에 상업 이용·수정 허용 및 에셋 재배포·재판매 금지 표시. |
| [Inventory system · Lukas Dumez](https://lukielue.itch.io/inventory-system) | 다운로드는 Unity 데모이며 페이지에 Franuka 아이콘 및 Kenney 오디오가 명시돼 있다. | 제작자는 댓글에서 상업 프로젝트 사용을 허용했다. 데모에서 꺼낸 개별 아이콘의 출처 팩까지는 확인하지 못했다. [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds)는 CC0이며, [Franuka RPG Icon pack 무료 샘플](https://franuka.itch.io/rpg-icon-pack-demo)은 별도로 상업 사용을 허용한다. |
| 색감 분석 자료 | `color-tone-blog/` | 글과 색 분석 도식. 압축에서 별도의 배포 조건을 확인하지 못했다. |
