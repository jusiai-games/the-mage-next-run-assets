# 컴포넌트 이미지 레퍼런스

`REFERENCE.zip`의 PNG 761장을 화면에서 쓰이는 용도에 따라 정리했다. 파일명에서 컴포넌트, 상태, 배율 또는 프레임 순서를 확인할 수 있다.

아래 경로와 수량은 로컬 레퍼런스 전체를 기준으로 한다. Git에는 출처 기록, 라이선스 문서와 Foozle의 스킬 아이콘을 포함한다. 나머지 원본은 기존 경로에 로컬로 보관한다.

| 폴더 | PNG | 찾을 수 있는 이미지 |
| --- | ---: | --- |
| [UI](UI/) | 197 | 버튼, 카드 뒷면과 프레임, 슬롯, 탭, 게이지, 입력 컨트롤, 패널 |
| [아이콘](아이콘/) | 419 | 인터페이스, 무기와 방어구, 아이템, 스킬, 상태 이상과 강화 |
| [이펙트](이펙트/) | 132 | 마법, 카드 찢어짐과 광택, 광석과 보석 애니메이션 |
| [아틀라스](아틀라스/) | 7 | 여러 컴포넌트가 들어 있는 원본 시트와 아틀라스 JSON |
| [색감 가이드](색감-가이드/) | 6 | OKLCH, 명암표 비교, 색상 회전, 제작 검수 도식 |

- [기본 버튼](UI/버튼/기본-버튼/)과 [정사각 슬롯](UI/카드와-슬롯/정사각-슬롯/)은 기본, 호버, 누름 또는 선택 등 상태별 파일을 한 폴더에 모았다. Questwood는 동일한 컴포넌트의 1x, 2x, 4x를 파일명으로 구분한다.
- [카드 찢어짐](이펙트/카드-찢어짐/)은 멀쩡한 카드에서 조각이 떨어지는 순서로 프레임 번호를 매겼다.
- [화염탄 아이콘](아이콘/스킬/화염탄/)처럼 여러 출처에 동일한 스킬 아이콘이 있는 경우 같은 폴더에서 비교할 수 있다.
- [원본 파일 이름 대조표](원본-파일-이름-대조표.csv)에 압축 속 경로, 정리한 경로, 이미지 크기와 원본 해시를 기록했다. [Questwood 에셋 좌표와 경계](Questwood-에셋-좌표와-경계.json)의 파일 경로와 [색감 분석 글](색감-가이드/색감-분석-글.md)의 이미지 링크도 새 위치로 연결했다.
- 원본 패키지의 안내문은 [출처와 라이선스](출처와-라이선스/)에 있다.
