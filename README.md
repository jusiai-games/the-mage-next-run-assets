# The Mage Next Run 에셋

**주문 넣고 갑니다 (Spells to Go)**의 제작 원본과 게임 적용용 에셋을 관리한다. 게임에 가져갈 파일은 [에셋 패키지 목록](exports/INDEX.md)에서 찾을 수 있다.

| 경로 | 내용 |
| --- | --- |
| `exports/<패키지>/` | Unity·Tiled에 가져갈 스프라이트, 애니메이션, 타일맵, UI와 사용 안내 |
| `sources/`, `approved/` | 제작 원본과 선별된 개별 프레임 |
| `manifests/`, `palettes/`, `styles/` | 제작 매니페스트, 팔레트, 스타일 프로파일 |
| `prototypes/`, `work/` | 화면 시안, 제작 스크립트와 재사용하는 중간 프레임 |
| `jobs/`, `art-direction.md` | 제작 작업 기록과 아트 방향 |
| `references/`, `.local/` | 출처·라이선스, 참고 에셋 및 로컬 이관 백업 |

## 패키지 관리

- 시트와 같은 이름의 `.sprite.json`, 타이밍 파일, Unity `.meta`를 해당 에셋과 함께 보관한다. Tiled 맵이 참조하는 이미지와 타일셋의 상대 경로를 유지한다. SVG와 편집 가능한 애니메이션 원본도 해당 패키지 또는 제작 원본과 함께 관리한다.
- 개별 파일로 관리하는 패키지의 중복 ZIP은 로컬에 둔다. 초원 색감 v2의 Unity 교체 ZIP과 그 안의 슬라임 패키지 ZIP에는 별도 메타데이터 또는 프레임이 있어 함께 보관한다.
- 이관 백업과 전송용 파일은 `.local/`에 둔다. 외부 레퍼런스는 [출처와 사용 조건](references/reference-components/출처와-라이선스/사용-조건-요약.md)을 기준으로 관리한다. 재배포 조건이 제한되거나 확인되지 않은 레퍼런스는 기존 경로에 로컬 파일로 보관한다.

## 제작 도구

기존 제작 스크립트는 작업별로 Pillow, Windows 글꼴, 픽셀 아트 제작 도구 또는 Unity 프로젝트를 사용한다. 슬라임·모바일 초원·색감 빌드는 같은 상위 폴더에 있는 `pixel-art-production`을 사용한다. 색감 빌드는 `the-mage-next-run` Unity 프로젝트도 사용한다. 완성된 에셋과 Tiled 맵을 가져오는 데에는 제작 스크립트가 필요하지 않다.
