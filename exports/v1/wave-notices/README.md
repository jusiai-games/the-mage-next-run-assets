# 스테이지 결과와 웨이브 알림 v1

## 결과 요약형

[승리·패배 미리보기](result-preview.png). 스테이지가 끝나면 공용 [나무틀 양피지](../spells-to-go-ui/package/Assets/SpellsToGo/UI/Sprites/NoticeParchment.png) 안에 결과 제목, 완료한 웨이브 수, 기본 [버튼](../spells-to-go-ui/package/Assets/SpellsToGo/UI/Sprites/button-normal.png)을 순서대로 중앙 배치한다. 실제 값은 Unity 텍스트로 그린다. 성공은 `victory-rule.png`와 녹색 제목 #315E4B, 패배는 `defeat-rule.png`와 적갈색 제목 #803F44를 사용한다. 두 장식선은 163×7px이며, 아래쪽에는 같은 색 1px 가로선을 사용할 수 있다. 확인 버튼은 본문과 분리하고 버튼 아래부터 창 외곽까지 시안 기준 24px 여백을 둔다.

## 픽셀 소거형 웨이브 알림

[등장·소거 미리보기](wave-preview.gif). 웨이브 효과가 적용될 때 효과별 카드 하나를 띄워 분류·원인과 실제 효과를 표시한다. 예시는 버프 ‘목표 일치 / 세 주문 강화’, 패널티 ‘목표 초과 / 첫 시전 2초 지연’이다. 버프와 패널티 모두 왼쪽에서 오른쪽으로 짧게 미끄러져 들어온 뒤 읽을 시간을 주고 왼쪽에서 오른쪽으로 픽셀 단위로 지운다.

| 이미지 | 크기 | 사용처 |
| --- | --- | --- |
| `buff-card.png` | 197×43 | 민트색 체크 카드. 윗줄 분류 색 #69EDB5 |
| `penalty-card.png` | 197×43 | 주홍색 느낌표 카드. 윗줄 분류 색 #FF815F |
| `erase-mask.png` | 1576×86 | 카드와 두 줄 텍스트에 함께 적용하는 공용 알파 마스크 |
| `buff-erase.png` | 1632×110 | 버프 소거 경계에 올라오는 빛 조각 |
| `penalty-erase.png` | 1632×110 | 패널티 소거 경계에서 아래로 흩어지는 잔상 |

텍스트는 카드 좌상단 기준 x=41에서 시작한다. 분류·원인은 y=5, 효과 설명은 y=16에 배치하며 효과 설명 색은 #FFF2DC다. 세 시트는 8열×2행, 좌상단부터 행 우선으로 읽는다. 마스크 셀은 197×43px, 파티클 셀은 204×55px이며 파티클 셀의 (0, 6)을 카드 좌상단에 맞춘다. 16프레임을 50ms 간격으로 한 번 재생한다. 마지막 프레임에는 카드와 파티클이 모두 사라진다. GIF와 PNG 미리보기는 검토에 사용한다.
