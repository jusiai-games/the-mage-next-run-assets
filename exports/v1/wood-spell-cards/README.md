# 나무 명판 주문 카드 v1

초안. 웨이브 준비의 손패와 장착 슬롯, 전투의 스킬 슬롯에 같은 원소별 카드 앞면을 쓴다. 갈색 나무 테두리, 회청색 조약돌, 원소색 이름 띠와 밝은 숫자 칸을 적용했다.

| PNG | 크기 | 용도 |
| --- | --- | --- |
| `CardFire.png`, `CardLightning.png`, `CardIce.png` | 44×64 | 불·번개·얼음 카드 앞면 |
| `SlotEmpty.png` | 44×64 | 비어 있는 장착 슬롯 |
| `SlotFlash.png` | 44×64 | 전투 발동 시 앞면 위에 겹치는 투명 테두리 |
| `ChargeTrack.png` | 44×5 | 충전 게이지 배경 |
| `ChargeFill.png` | 42×3 | 게이지 배경의 (1, 1)에 놓고 충전량에 따라 가로로 잘라 표시 |

주문명과 카드 숫자는 게임에서 각각 가로 중앙(x=22)에 맞춰 그린다. 44×64 기준으로 이름 띠의 범위는 x=4–39, y=37–44이며, 숫자나 설명을 넣는 밝은 영역은 x=5–38, y=46–60이다. 배율을 조절할 때 픽셀 경계를 유지하려면 Point 필터를 사용한다.


## 기본 전투 주문 5종 · AI 카드 제작

파이어 볼트, 아이스 볼트, 차지드 볼트, 매직 볼트, 매직 실드 카드를 만들 때는 [기본 주문 매핑](skill-art/basic/manifest.json)을 먼저 읽는다. [다섯 장 비교](skill-art/basic/preview.png)는 매핑 순서대로 배치되어 있다.

1. 표시 이름은 `nameKo`, 조회 키는 `id`를 쓴다. 매직 미사일(Magic Missile)은 매직 볼트(`magic-bolt`)로 찾는다. 파일 경로의 기준은 모두 `exports/v1/`이다.
2. `frame`을 열고 투명 PNG `art`를 원래 크기 28×26px로 (8, 8)에 합성한다. 44×64px 카드에 주문명과 게임에서 받은 숫자를 위의 이름 띠와 숫자 칸에 그린다. 배율은 정수배, 필터는 Point를 쓴다.
3. 새 변형을 그릴 때는 `art`를 구도 기준으로, `motif`와 `effectSheet`를 형태·색상 기준으로 삼는다. 매직 볼트와 매직 실드는 번개 카드와 같은 남색 이름 띠 프레임을 쓴다. 매직 실드의 `blockSheet`는 피격 섬광 참조다.

## 희생 이펙트 · 불씨로 흩어짐

[미리보기](sacrifice/preview.gif) · [프레임 정보](sacrifice/manifest.json)

카드의 아래쪽부터 타들어 가며 불씨가 위로 흩어진다. 시트 두 장은 각각 640×282px이며 80×94px 셀을 왼쪽 위부터 행 우선으로 읽는다. 24프레임을 프레임당 50ms로 한 번 재생한다.

1. 셀의 (18, 16)에 희생된 카드 앞면과 중앙 정렬된 주문명·숫자를 합성한다.
2. 같은 프레임의 `embers-mask.png` 알파로 카드와 글씨를 함께 가린다. 불투명한 흰색 픽셀이 남아 있는 부분이다.
3. `embers-overlay.png`의 같은 프레임을 위에 겹친다. 마지막 프레임에서 두 레이어 모두 투명해진다.

## 희생 후 숫자 변경 · 불티 스캔

[미리보기](number-change/preview.gif) · [프레임 정보](number-change/manifest.json)

숫자를 바꿀 수 있는 카드에는 희생이 끝난 뒤 선택 표시를 보여 준다. 카드를 선택하면 선택 표시를 닫고 해당 카드의 숫자 칸에서 스캔을 한 번 재생한다.

두 시트는 각각 192×36px이며 24×18px 셀을 좌상단부터 행 우선으로 읽는다. 카드의 (10, 46)에 맞춰 16프레임을 프레임당 50ms로 재생한다. `scan-mask.png`는 기존 숫자의 알파에만 적용하고, `scan-overlay.png`를 같은 위치에 겹친다.

0부터 센 11번 프레임에서 새 숫자를 가로 중앙에 표시한다. 굵은 적갈색(`#A12E24`), 기존 대비 약 1.26배 크기, 밝은 외곽선(`#FFF0B7`)을 사용한다. 화살표 없이 변경된 값 하나를 유지한다.
