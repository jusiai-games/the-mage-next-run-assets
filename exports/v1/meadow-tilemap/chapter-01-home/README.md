# 챕터 1 홈 화면

| 파일 | 용도 |
| --- | --- |
| [background.png](background.png) | 제목과 버튼을 지운 일러스트 배경. 마법사 포함 |
| [button-game-start.png](button-game-start.png) | 원본 표지에서 추출한 투명 PNG. 게임 시작 문구 포함 |
| [preview.png](preview.png) | 제목과 버튼을 포함한 전체 배치 참고 이미지 |
| [manifest.json](manifest.json) | 원본 캔버스, 버튼 픽셀 좌표와 제목 문구 |

배경과 버튼 좌표는 971×1620px 원본의 좌상단 기준이다. 제목은 매니페스트 문구를 UI 텍스트로 배치한다. 배경에서 타이틀과 버튼이 있던 부분은 이미지 생성 편집으로 복원했다. Unity 화면에 연결하기 전의 PNG 에셋이다.

스테이지 시작용 배경과 공통 전투 시작 버튼은 [스테이지 1~3 패키지](../stages/README.md)에 있다.
