# 표지 디자인 마법사

첨부 캐릭터의 적갈색 머리, 보라 망토와 청록 수정을 사용한 오른쪽 전투 스프라이트 제작 패키지다. 게임 적용본은 기존 이름과 경로를 유지한 [wizard 패키지](../wizard/README.md)에서 사용한다. [전체 프레임 비교판](preview.png)은 위에서부터 대기, 걷기, 시전, 쓰러짐이다.

| 상태 | PNG | 프레임 및 재생 |
| --- | --- | --- |
| 대기 | [시트](idle/title_hero_idle.png) | 5프레임, 프레임당 200ms, 반복 |
| 걷기 | [시트](walk/title_hero_walk.png) | 8프레임, 프레임당 50ms, 반복 |
| 시전 | [시트](cast/title_hero_cast.png) | 8프레임, 30 Samples, 키 0·1·3·4·5·6·7·8 |
| 쓰러짐 | [시트](fall/title_hero_fall.png) | 6프레임, 30 Samples, 키 0·1·3·5·8·11, 마지막 포즈 유지 |

셀 32×32px, 좌상단 원점 기준 발 피벗 (16, 28), 32 PPU. 걷기와 시전은 기존 프레임의 식별자를 유지하려고 중간 프레임을 시트 오른쪽에 추가했다. 재생 순서는 timing.json의 playback_frame_order_zero_based에서 읽는다. Unity 분할과 이름은 같은 이름의 .sprite.json을 읽는다. 애니메이션 키와 이벤트는 각 timing.json을 사용한다.

시전 시작 100ms에 세 번째 프레임의 지팡이 끝 (28, 14)에서 투사체를 발사한다. 투사체는 기존 게임 이펙트를 함께 사용한다. 시전 중 발밑은 y=27을 유지하고, 머리는 대기보다 1px만 낮아진다. 대기 첫 프레임은 시전 시작·회복 끝 및 쓰러짐 시작과 동일하다.

걷기와 시전은 첨부 동작의 몸통과 팔다리를 사용하고, 머리와 얼굴에는 대기 기준 포즈의 동일한 픽셀을 썼다. 걷기의 손과 지팡이 사이를 연결하고 실루엣 밖에 분리된 픽셀을 정리했다. 대기 중에는 어깨와 몸통 위치를 고정하고 망토 주름의 명암만 변한다. 쓰러짐은 첨부에 해당 포즈가 없어 피격에서 착지까지 원래 6프레임과 재생 키를 사용한다. 회전 포즈에서도 다른 동작과 같은 팔레트 및 외곽선 규칙을 적용했다. [제작 스크립트](render.ps1)는 사용자가 첨부한 원본 PNG를 -Source로 받는다.




불투명 픽셀 기준 공유 팔레트는 28색이다.
대기 원본 축소에서 허리를 가로지르던 검은 픽셀 띠를 망토와 가죽 띠 색으로 재배치했다. 색상 수를 줄이기 전 팔레트를 복원했다. 어두운 외곽 픽셀을 명확히 하고 망토, 가방과 피부의 내부 명암은 유지했다.


스태프의 청록 수정과 금빛 소켓은 첨부 원화의 픽셀을 사용한다. 대기와 걷기에서는 소켓 아래 막대 픽셀만 재배치해 축을 정리했다. 스태프가 없는 걷기 포즈 두 장은 대기 프레임의 수정과 소켓을 옮겨 썼다.


걷기는 0.4초 루프에 새 발 교차 자세를 넣었다. 시전은 발사, 반동과 회복 사이에 중간 자세를 추가했다. 손이 스태프를 잡는 픽셀을 겹치게 보정했다.
