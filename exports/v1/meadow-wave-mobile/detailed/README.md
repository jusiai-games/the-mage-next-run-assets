# 모바일 전투 배경 · 스테이지 1~3

[세 전장 비교](preview.png) · [배치 매니페스트](manifest.json)

전투 마법사의 남색 그림자와 구릿빛 하이라이트에 맞춰 산·언덕의 그림자를 푸른 회색으로 옮기고, 길가의 흙과 돌에 따뜻한 색을 넣었다. 비교판에는 캐릭터와 지면이 맞닿는 위치에 발밑 그림자를 합성했다.

| 스테이지 | 전투 화면 | 편집용 지형 |
| --- | --- | --- |
| 1 들꽃 언덕 | [PNG](stage-01/preview.png) | [Tiled 맵](stage-01/terrain.tmj) |
| 2 솔바람 고개 | [PNG](stage-02/preview.png) | [Tiled 맵](stage-02/terrain.tmj) |
| 3 노을마루 | [PNG](stage-03/preview.png) | [Tiled 맵](stage-03/terrain.tmj) |

스테이지 폴더의 `battle.tmj`를 열면 산·언덕 이미지 레이어와 전장 타일을 한 화면에서 편집할 수 있다. `terrain.tmj`는 지형만 담는다.

- 들꽃 언덕의 24px 길은 완만하게 굽고, 가장자리에 분홍 들꽃이 모여 있다.
- 솔바람 고개의 20px 길은 더 가늘고, 소나무 아래에 잔자갈이 이어진다.
- 노을마루의 22px 길은 넓은 곡선을 그리고, 길 아래쪽에 마른 풀을 배치했다.

160×352px 세로 카메라 기준이며, 좌상단 좌표와 아래 그리기 순서를 쓴다.

| 레이어 | 크기 | 배치 |
| --- | --- | --- |
| `mountains.png` | 160×80px | (0, 0) |
| `foothills.png` | 160×32px | (0, 55), 투명 중간 언덕, 충돌 없음 |
| `battlefield.png` | 160×144px | (0, 80), 풀밭과 전투 오솔길 |
| 공용 주문 패널 | 160×128px | (0, 224) |

지면을 타일로 배치할 때는 같은 폴더의 `terrain.tmj`와 `terrain-tiles.png`를 사용한다. 16×16px, 10열×9행 고정 맵이며 타일 배치와 합성 PNG의 픽셀이 일치한다. 원경과 언덕은 고정 화면 레이어다. 마법사 발 좌표는 기존 (24, 153)을 사용한다. 비교판의 슬라임과 마법사는 화면 비율 검토용이다. Unity 씬 연결은 적용 전이다.

비교판의 슬라임은 원본 셀을 최근접 75%로 표시한다. 발 좌표 (129, 153)를 기준으로 축소하며 적용 배율은 매니페스트의 `slime_presentation.scale`에 기록했다.
