# 초원 색감 개선안 v2

[적용 전후 화면](meadow-before-after.png) · [색상 매핑](color-mapping.json) · [색감 프로파일](color-profile/profile.json) · [상태 전환 검수](transition-reports.json)

- 초원 슬라임은 기존 젤 명암에서 청록 기본색으로 옮겼다. 전진, 공격, 대기, 피격, 사망에 같은 매핑을 적용했다.
- 초원 바닥은 채도를 낮춘 따뜻한 올리브로 옮기고, 원경에는 푸른 안개색을 섞었다. 덤불의 중간톤은 원경과 바닥 사이를 잇는다.
- 마법사 로브는 푸른 보라 중간색을 밝히고 가죽과 피부의 따뜻한 색은 살렸다. 번개와 시전 효과는 얼음빛으로, 주문 UI 강조색은 부드러운 금색으로 다듬었다.

## Unity에서 확인하기

ZIP의 `Assets/`를 프로젝트 루트에 복사하고 15개 PNG와 함께 제공하는 `.sprite.json`을 교체한다. 프로젝트의 기존 `.meta` 파일을 사용한다. `ColorPassDocs/`에는 비교 화면, 제작용 PNG·GIF·시트와 팔레트가 있다.

프레임 크기, 피벗, 알파, 타일 배치, 재생 시간과 이벤트를 원본과 대조했다. Unity 프로젝트에 직접 적용하거나 플레이 모드에서 실행하는 검수는 별도로 진행한다. 프로파일은 캐릭터 두 종과 초원 지형·원경의 초기 기준이다. 효과 레퍼런스는 번개 한 종이라 통계는 자료 부족으로 표시한다.
