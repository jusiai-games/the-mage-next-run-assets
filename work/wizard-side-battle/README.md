# 오른쪽 옆모습 전투 마법사

[비교판](comparison.png)은 기존 대기 첫 프레임과 오리지널 옆모습 시안을 4배 확대 및 초원 위 1배로 보여준다. 첨부된 전투 도트처럼 머리와 몸통이 함께 오른쪽을 향하고 앞뒤 팔다리는 일부 겹친다. 구릿빛 머리, 보라 망토와 청록 수정 지팡이로 그렸다. 캐릭터 실물 높이는 22px이며, 얼굴은 한 픽셀 눈과 이어지는 피부색 면으로 구성했다.

[스프라이트 PNG](hero-wizard.png)는 32×32px 투명 정지 포즈다. 발 피벗은 좌상단 기준 (16, 28), 32 PPU다. 디자인 검토용이다. [제작 스크립트](render.ps1)는 PNG를 생성하고 투명도와 발 기준선을 검사한다.
