# 후드 마법사 주인공 시안

[비교판](comparison.png)은 기존 대기 첫 프레임과 새 포즈를 최근접 4배 확대 및 기존 초원 위 1배로 보여준다. 뒤로 눕힌 남색 후드, 또렷한 옆얼굴, 길게 떨어지는 망토와 굽은 나무 지팡이로 실루엣을 정리했다.

[주인공 PNG](hero-wizard.png)는 오른쪽을 향한 32×32px 투명 정지 포즈다. 좌상단 기준 발 피벗은 (16, 28), 32 PPU다. 디자인 검토용이며 게임 적용에는 상태별 시트가 필요하다. [제작 스크립트](render.ps1)는 PNG와 비교판을 다시 그리고 투명도와 발 기준선을 검사한다.
