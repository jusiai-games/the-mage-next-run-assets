# 후드 마법사 수정 시안

[비교판](comparison.png)은 기존 후드 마법사와 수정 시안을 최근접 4배 확대 및 초원 위 1배로 보여준다. 수정 시안은 좁은 후드, 길게 떨어지는 비대칭 망토, 가느다란 나무 지팡이, 앞뒤로 벌린 장화에 중점을 둔다.

[스프라이트 PNG](hero-wizard.png)는 오른쪽을 향하는 32×32px 투명 정지 포즈다. 발 피벗은 좌상단 기준 (16, 28), 32 PPU다. 디자인 검토용이다. [제작 스크립트](render.ps1)는 PNG와 비교판을 생성하고 투명도와 발 기준선을 검사한다.
