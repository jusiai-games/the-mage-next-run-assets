# 복원본 망토와 다리 교차 자세 검토

[비교 GIF](comparison.gif)의 왼쪽은 이전 8프레임 복원본, 오른쪽은 게임에 적용할 10프레임 채택본이다. 두 버전 모두 한 주기는 400ms다. 오른쪽 시트는 복원본에서 얼굴, 팔, 지팡이와 망토를 각 시점에 맞춰 가져온다. 지지발은 땅에 닿은 채 뒤로 이동하고 반대 발은 몸 아래를 지나 앞으로 나온다.

[시트](walk-review.png)는 32×32 셀 10장이 왼쪽부터 재생 순서로 들어 있다. 발 피벗은 (16, 28)이다. 프레임 지속 시간은 50, 30, 20, 50, 50, 50, 30, 20, 50, 50ms다. 두 번째와 일곱 번째 상체 자세가 유지되는 동안 하체의 중간 자세를 한 장씩 더 보여준다.
