# 걷기 10프레임 정리

[이전 GIF](before.gif)와 [정리 후 GIF](after.gif)를 비교한다. [비교판](compare.png)은 위가 이전, 아래가 정리 후다.

이전 시트는 지팡이를 가슴에 든 상체와 팔을 앞으로 뻗은 상체가 프레임마다 바뀌어 지팡이·팔·망토가 깜빡였고, 다리는 회색 덩어리로 겹쳐 보폭이 읽히지 않았다.

정리 후 시트는 다음과 같다.

- 상체는 대기 포즈와 같은 얼굴·지팡이 자세 한 가지로 고정했다. 허리 아래로 드러나던 피부색 무릎 블록은 코트 색으로 바꿨다.
- 다리는 16비트 RPG 필드 캐릭터처럼 짧고 굵게 새로 그렸다. 바지는 안쪽 3px, 장화는 발목 띠·발등·밑창 세 줄이다. 앞다리는 밝은 회색 바지와 갈색 장화, 뒷다리는 어두운 톤이다.
- 걸음은 16비트 RPG 필드 걸음처럼 세 자세를 끊어서 보여준다. 앞다리를 내민 자세 A → 다리를 모은 자세 → 뒷다리를 내민 자세 B → 다리를 모은 자세 순서이며, 발은 들지 않고 바닥(y=27)에 붙어 있다. 벌린 자세는 같은 중심(x=14.5)에서 앞뒤 3px, 모은 자세는 1px이다.
- 다리를 모은 자세에서는 몸이 1px 올라가 통통 튀는 리듬을 만든다. 망토 끝은 몸보다 한 박자 늦게 따라오고, 다리를 벌린 두 자세에서는 1px 더 뒤로 펄럭인다.
- B 자세에서는 지팡이와 쥔 손이 1px 앞으로 나가 지팡이를 짚으며 걷는 리듬을 준다. 뒤로 당기면 수정이 머리에 붙어서 A 자세는 제자리다.
- 프레임 수, 셀 크기, 발 피벗 (16, 28), 프레임 지속 시간은 그대로다. 프레임별 자세는 A, 모음, 모음, 모음, B, B, 모음, 모음, 모음, A이고, timing.json의 지속 시간과 합치면 네 자세가 각각 100ms씩 유지된다.
- 기존 팔레트 안의 26색만 사용했다.

[build_walk.py](build_walk.py)가 [이전 시트의 첫 프레임](source-frame-00.png)에서 상체를 가져와 시트를 다시 만든다.

```powershell
py work/wizard-walk-clean/build_walk.py . exports/v1/wizard/walk/hood_staff_walk.png
```
