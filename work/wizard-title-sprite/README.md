# 표지 마법사 스프라이트

[비교판](comparison.png)은 기존 대기 첫 프레임과 표지 캐릭터 시안을 최근접 4배 및 초원 위 1배로 보여준다. 적갈색 앞머리, 금장 보라색 망토, 가죽 가방, 청록 수정 지팡이를 32×32 격자에 맞춰 그렸다. 첨부 전투 도트의 3/4 자세를 참고해 머리를 어깨 위에 두고 몸통을 세웠다. 망토는 어깨에서 아래로 떨어지고 두 장화는 간격을 두고 지면을 딛는다.

[스프라이트 PNG](hero-wizard.png)는 오른쪽 3/4 방향의 32×32px 투명 정지 포즈다. 발 피벗은 좌상단 기준 (16, 28), 32 PPU다. 디자인 검토용이다. [제작 스크립트](render.ps1)는 비교판과 PNG를 생성하고 알파와 발 기준선을 검사한다.
