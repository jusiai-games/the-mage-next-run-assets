# 마법사와 초원 슬라임 리디자인 시안

[비교판](comparison.png)은 기존 대기 첫 프레임과 세 시안을 4배 최근접 확대 및 모바일 초원 위 1배로 보여준다. 마법사와 슬라임은 각 열에서 독립적으로 골라 조합할 수 있다.

| 시안 | 마법사 | 초원 슬라임 |
| --- | --- | --- |
| A | [별우편 마법사](a-wizard.png) · 보라색으로 휘어진 모자, 금빛 띠와 별 지팡이 | [이슬방울 슬라임](a-slime.png) · 끝이 말린 물방울, 청록색 젤과 작은 볼터치 |
| B | [달빛 마법사](b-wizard.png) · 푸른 후드, 민트색 초승달 지팡이 | [복숭아 슬라임](b-slime.png) · 갈라진 윗선, 산호색 젤과 웃는 입 |
| C | [꽃잎 마법사](c-wizard.png) · 꽃잎 모자, 장밋빛 망토와 꽃봉오리 지팡이 | [새싹 슬라임](c-slime.png) · 두 잎 새싹, 연두색 젤과 볼터치 |

각 PNG는 32×32px 투명 대기 키 포즈 한 장이다. 좌상단 기준 피벗은 (16, 28), 검토 기준은 32 PPU다. 마법사는 오른쪽, 슬라임은 왼쪽을 향한다. 파일 용도는 디자인 검토이며 기존 전투 패키지의 배치, 발사점과 프레임 타이밍은 해당 패키지 문서를 따른다.

[제작 스크립트](render.ps1)는 정수 픽셀 좌표에서 원본을 그려 6개 PNG와 비교판을 생성한다. 알파가 0 또는 255이고 불투명 픽셀이 발 기준선 위에 들어오는지 검사한다.
