# 전투 마법사와 초원 슬라임 리디자인

[비교판](comparison.png)은 기존 대기 첫 프레임과 새 조합 3종을 4배 확대 및 모바일 초원 위 1배로 보여준다.

| 시안 | 마법사 | 슬라임 |
| --- | --- | --- |
| A | [잿불 추적자](a-wizard.png) · 눈을 가리는 챙, 적갈색 망토, 불씨 지팡이 | [용암핵 슬라임](a-slime.png) · 검붉은 껍질과 밝게 드러난 핵 |
| B | [폭풍 전투마법사](b-wizard.png) · 푸른 금속 어깨갑옷과 전기가 흐르는 갈래 지팡이 | [전격 슬라임](b-slime.png) · 앞쪽으로 낮게 기운 몸과 번개 무늬 |
| C | [봉인 집행관](c-wizard.png) · 금속 가면과 고리형 봉인 지팡이 | [흑요석 슬라임](c-slime.png) · 불규칙하게 솟은 결정과 호박색 눈 |

모든 PNG는 32×32px 투명 대기 키 포즈다. 발 피벗은 좌상단 기준 (16, 28), 32 PPU다. 마법사는 오른쪽, 슬라임은 왼쪽을 향한다. 조합은 디자인 검토용이며 게임 적용과 애니메이션 제작은 채택 후 진행한다.

[제작 스크립트](render.ps1)는 여섯 PNG와 비교판을 재생성하고 투명도 및 발 기준선을 검사한다.
