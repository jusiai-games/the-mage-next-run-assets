# 후드 마법사와 초원 슬라임 성격 시안

[비교판](comparison.png)은 기존 스프라이트와 세 가지 대기 포즈 시안을 4배 확대 및 기존 초원 위 1배로 보여준다. 남색 후드와 나무 지팡이, 청록색 젤 몸체를 기준으로 표정과 소품을 바꿨다.

| 시안 | 후드 마법사 | 초원 슬라임 |
| --- | --- | --- |
| A | [허세 부리는 신참](a-wizard.png) · 겁날수록 한쪽 입꼬리를 올린다. 짧은 적갈색 머플러가 뒤로 흐른다. | [심술쟁이](a-slime.png) · 비스듬한 눈매와 한쪽으로 말린 입 |
| B | [끝까지 버티는 녀석](b-wizard.png) · 후드를 깊이 쓰고 턱을 당긴다. 해진 망토를 기워 입고 손때 묻은 지팡이를 쓴다. | [오기 많은 녀석](b-slime.png) · 눈을 가늘게 뜨고 입을 꾹 다문 표정 |
| C | [말보다 행동](c-wizard.png) · 후드 아래 삐져나온 머리카락, 담담한 눈매, 오래된 황동 망토 고리 | [눈치 빠른 녀석](c-slime.png) · 비대칭 눈과 작은 입으로 상대를 살피는 표정 |

개별 PNG는 32×32px 투명 정지 포즈이며 발 피벗은 좌상단 기준 (16, 28), 기준 배율은 32 PPU다. 마법사는 오른쪽, 슬라임은 왼쪽을 향한다. 디자인 검토용이다.

[제작 스크립트](render.ps1)는 기존 대기 첫 프레임 위에 픽셀을 편집해 PNG를 생성하고 투명도와 발 기준선을 검사한다.
