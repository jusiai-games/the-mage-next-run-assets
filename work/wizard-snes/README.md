# 후드 마법사 16비트 전투 도트 시안

[비교판](comparison.png)은 기존 첫 대기 프레임과 새 시안을 최근접 4배 확대 및 초원 위 1배로 비교한다. 첨부 전투 스프라이트를 참고해 얼굴, 남색 후드, 가죽 장비를 굵은 명암 덩어리로 그렸다.

[스프라이트 PNG](hero-wizard.png)는 오른쪽을 향한 32×32px 투명 정지 포즈다. 발 피벗은 좌상단 기준 (16, 28), 32 PPU다. 디자인 검토용이다. [제작 스크립트](render.ps1)는 픽셀 색을 행별로 기록하고 알파와 발 기준선을 검사한다.
