# 마법사 도트 제작 방식 비교

[비교판](comparison.png)은 기존 마법사와 두 시안을 최근접 4배 및 초원 위 1배로 보여준다.

- [A · 전투 도트](retro-wizard.png)는 마지막 첨부의 작은 전투 도트를 참고해 22px 높이의 오른쪽 포즈를 직접 그렸다. 눈, 얼굴, 머리와 망토 명암은 큰 색 덩어리로 표현했다.
- [B · 기존 포즈 기반](original-pose-wizard.png)은 기존 오른쪽 대기 첫 프레임을 기준으로 머리, 망토 팔레트, 금장과 청록 수정을 다시 찍었다. 기존 제작 명세의 셀, 발 피벗과 지팡이 그립을 사용한다. 얼굴은 오른쪽 옆모습으로 좁게 잡고, 눈은 짙은 윗픽셀과 청회색 아랫픽셀을 한 열에 찍었다. 머리는 낮고 평평한 윗선에서 뒤로 쓸어 넘기고, 관자놀이 뒤의 끝을 계단형으로 꺾었다. 눈과 볼의 앞선을 같은 열로 맞추고 턱 끝을 한 칸 안으로 넣었다. 입 선은 생략했다.

두 PNG는 32×32px 투명 정지 포즈로 발 피벗은 (16, 28), 32 PPU다. 기존 제작 명세의 동작 시트 제작과 전환 검수에 앞선 디자인 비교용이다. [제작 스크립트](render.ps1)는 PNG와 비교판을 생성하고 이진 알파와 발 기준선을 검증한다.
