# 카드 희생 이펙트 시안

비교 GIF는 20 FPS로 재생한 뒤 빈 손패 자리를 잠시 보여 준다. 가운데 카드에만 이펙트를 적용했다.

| 시안 | 투명 PNG 시트 |
| --- | --- |
| 불씨로 흩어짐 | embers.png |
| 룬으로 흡수 | rune.png |
| 명판 파쇄 | shards.png |
| 마력으로 증발 | dissolve.png |

시트는 640×282px, 8열×3행이다. 셀은 80×94px이며 좌상단부터 행 우선으로 24프레임이다. 각 프레임은 50ms다. 원본 카드(44×64px)의 좌상단은 셀 기준 (18, 16)이며 마지막 프레임은 완전히 투명하다. 시트는 카드 앞면을 포함한 시안 검토용이다.
