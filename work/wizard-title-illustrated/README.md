# 마법사 일러스트 타이틀

[챕터 1 배경으로 수정한 시안](chapter-01/README.md)

[타이틀 화면 시안](preview.png) · [이미지 생성 프롬프트](prompt.txt)

적갈색 머리, 남색 망토, 여행 가방을 살려 마법사를 만화풍으로 새로 그린 홈 화면 콘셉트다. 석문과 산길에는 망토와 같은 방향의 저녁빛을 두고, 지팡이의 청록 결정과 황동을 시작 버튼에 반복했다.

내장 이미지 생성 도구로 만든 세로 합성 검토본이다. 캐릭터, 배경, 제목, 버튼이 한 이미지에 합성되어 있다. 채택 후 실제 20:9 레이아웃에 맞춰 배치하고 버튼을 개별 UI로 제작한다.
