# 챕터 1 타이틀

[홈 화면 시안](preview.png) · [편집 프롬프트](prompt.txt)

[배경과 버튼을 분리한 v1 에셋](../../../exports/v1/meadow-tilemap/chapter-01-home/README.md)

초원 오솔길에서 뒤집힌 수레와 찢어진 깃발을 지나 대도시로 향한다. 오른쪽 성벽 하단의 등불과 철창 문은 도적들이 숨은 지하 던전 입구를 암시한다. 앞선 타이틀의 주인공을 바탕으로 얼굴, 적갈색 머리, 망토와 지팡이 실루엣을 살렸다.

내장 이미지 생성 도구를 사용했다. 제목·버튼·캐릭터·배경을 한 장에 담은 정지 검토본이다. 레이어 배치와 버튼 동작은 Unity 홈 화면 적용 시 연결한다.
