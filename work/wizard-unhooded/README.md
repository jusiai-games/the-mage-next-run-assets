# 후드를 벗은 마법사

[비교판](comparison.png)은 기존 대기 첫 프레임과 머리만 수정한 시안을 최근접 4배 확대 및 초원 위 1배로 보여준다. 첨부 이미지의 에드거 헤어에서 곧게 뻗은 밝은 앞머리와 짧게 묶인 뒷머리를 참고했다. 첨부된 16비트 전투 도트를 참고해 앞머리 아래에 눈 흰자와 짙은 눈동자를 배치하고 턱에 한 단계 낮은 피부색을 썼다. 코 돌출과 입 선은 생략했다. 제작 스크립트는 편집한 머리 영역 밖 픽셀을 원본과 비교한다.

[스프라이트 PNG](hero-wizard.png)는 오른쪽을 향한 32×32px 투명 대기 포즈다. 발 피벗은 좌상단 기준 (16, 28), 32 PPU다. 디자인 검토용이다.
