앱 진입 홈 화면 기준이다. 160×352px의 20:9 세로 프레임에 `background.png`, `wizard.png`, `ui.png`를 좌상단 (0, 0)에 순서대로 합성했다. 버튼의 논리 픽셀 사각형은 (32, 288, 96, 33)이다. 정지 시안이며, `ui.png`의 버튼 그림은 조작 가능한 컨트롤을 배치할 때 위치 기준으로 쓴다.

세 장면의 주인공은 [후드를 벗은 마법사](../wizard-unhooded/README.md)의 32×32px 대기 포즈다. 좌상단 (16, 28) 발 피벗을 기준으로 각각 3배, 3배, 4배 최근접 확대했다. 비교판은 각 장면의 2배 확대다. Unity 홈 화면 적용 전 디자인 검토용이다.
