# 망토 마법사 전투 시안

[비교판](comparison.png)은 기존 대기 첫 프레임과 새 시안을 4배 확대 및 초원 위 1배로 보여준다. 첨부 이미지 왼쪽 아래 전투 도트의 밝은 머리 윤곽, 어깨 망토와 앞으로 내민 손을 참고했다. 얼굴과 시전 손은 오른쪽을 향하며, 금발은 위로 솟은 앞머리와 어깨 뒤로 이어지는 가닥으로 그렸다. 마지막 첨부 전투 도트의 비율에 맞춰 머리를 좁히고 다리를 길게 잡았다. 지팡이의 축은 한 픽셀 열로 곧게 뻗는다.

[스프라이트 PNG](hero-wizard.png)는 32×32px 투명 정지 포즈다. 발 피벗은 좌상단 기준 (16, 28), 32 PPU다. 디자인 검토용이다.
