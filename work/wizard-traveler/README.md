# 후드 마법사 여행자 시안

[비교판](comparison.png)은 기존 대기 첫 프레임과 세 가지 새 포즈를 최근접 4배 확대 및 기존 초원 배경 위 1배로 보여준다. 첨부 레퍼런스에서 절제된 표정과 여행자다운 소품이라는 방향을 참고해 남색 후드, 나무 지팡이, 갈색 여행 장비를 중심으로 디자인했다.

| 시안 | 성격과 포즈 |
| --- | --- |
| [A · 주문 수집가](a-wizard.png) | 실패한 주문까지 챙겨 둔다. 낡은 허리 가방 밖으로 종이가 삐져나오고, 시선은 앞을 향한다. |
| [B · 허세 섞인 여유](b-wizard.png) | 위험할수록 태연한 척한다. 지팡이를 어깨 뒤로 가로질러 메는 자세가 특징이다. |
| [C · 한 박자 먼저](c-wizard.png) | 말없이 먼저 대비한다. 청록 천이 뒤로 흐르고, 손에 든 지팡이에 희미한 마력이 맺힌다. |

개별 PNG는 32×32px 투명 배경, 오른쪽 방향 정지 키 포즈. 발 피벗은 좌상단 기준 (16, 28), 32 PPU다. 디자인 검토용이며 전투 적용에는 채택한 디자인의 상태별 시트 제작이 필요하다.

[제작 스크립트](render.ps1)는 PNG와 비교판을 생성하며 투명도와 발 기준선을 검증한다.
