# 주문 손패 카드 시안

- 대상은 주문 장착 화면의 손패다. 현재 장착 영역 위쪽의 슬롯을 배치 기준으로 사용한다.
- 마법서, 봉인, 원소의 세 방향을 비교한다. 비교 카드의 주문은 화염탄, 연쇄 번개, 마력 폭발이다.
- 카드 프레임은 공통 44×64 논리 픽셀을 가정한다. 기존 주문 스프라이트를 삽화에 쓰고 주문명과 적용 조건은 확대 화면에서 별도로 그린다.
- 마법서는 양피지와 나무 테두리, 봉인은 어두운 카드지와 룬 원, 원소는 원소별 삽화와 이름 띠를 쓴다.
- 장착 화면은 기존 전투 배경에서 딤 처리된 화면을 기준으로 하고 한 손패 안에서 가운데 카드를 들고 바깥 카드가 살짝 겹치도록 배치한다.

## 시안 반영

C 원소 방향을 선택했다. 주문 아이콘은 삽화 영역 안에서 작게 두고, 카드 앞면 하단의 약 38%를 설명에 쓴다. 짙은 원소색 띠에 밝은 주문명을, 밝은 설명란에 짙은 효과와 장착 조건을 렌더링한다.
