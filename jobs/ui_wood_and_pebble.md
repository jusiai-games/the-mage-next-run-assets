# 나무와 조약돌 UI

- 대상 화면은 가로 320×180 논리 픽셀의 초원 전투 시안이다. 버튼은 32×24px, 창·카드 프레임은 32×32px로 제작한다.
- 버튼과 창은 따뜻한 나뭇결, 짙은 갈색 음영, 비대칭 회청색 조약돌을 공유한다. 글자가 올라가는 중앙은 단색 면으로 유지한다.
- 재질 시안에 사용한 프롬프트는 정면의 넓은 대화 창과 기본·호버·누름 버튼을 배치하고, 계단형 픽셀 외곽, 수평 나뭇결, 작은 모서리 조약돌, 어두운 창 안쪽을 그리도록 했다.
- 게임용 PNG는 재질 시안을 바탕으로 `prototypes/meadow-visual/ui_art.py`에서 픽셀 단위로 다시 제작한다. 사용 색은 `palettes/project.json`의 기존 색이다. 9슬라이스 고정 경계는 상하 6px, 좌우 8px다.
