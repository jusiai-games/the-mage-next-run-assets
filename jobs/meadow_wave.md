# 초원 웨이브 화면

- 레퍼런스는 사용자가 첨부한 세로 전투 화면과 https://www.youtube.com/watch?v=4JjS4rIrKt0&t=40s 링크다. 화면 분할과 우측에서 접근하는 적, 하단 주문 슬롯을 참고한다.
- 후드 마법사 오른쪽 대기 00을 그대로 사용한다. 셀 32×32, 발 피벗 (16, 28). 초원 슬라임은 미리보기에만 배치한다.
- 모바일 산출물은 `exports/v1/meadow-wave-mobile/`에 둔다. 새 첨부 화면을 기준으로 160×352, 10×9 전투 타일맵, 6열×2행 주문 패널로 조정했다.

- 1번 시안에 따라 기존 초원 팔레트의 낮은 덤불과 풀을 경계에 배치했다. 생성 원본과 프롬프트는 sources/meadow_wave_hedge/01, 모바일 검수는 work/meadow_wave/mobile/validation.txt에 있다.

- 초원 생성 원본과 프롬프트는 sources/meadow_wave/01에 있다.
